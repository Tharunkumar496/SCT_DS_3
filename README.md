# 🌳 Decision Tree Classifier - Bank Marketing Prediction

## 📌 Project Description
This project demonstrates the implementation of a **Decision Tree Classifier** to predict whether a customer will subscribe to a bank term deposit based on various demographic and marketing-related features.
The project includes data preprocessing, model training, evaluation, and visualization of the decision tree using Python and Scikit-learn.
## 🎯 Objective
Build a machine learning model that can classify customers as likely or unlikely to subscribe to a bank term deposit based on historical marketing campaign data.
## 📂 Dataset
The dataset contains customer information such as:
- Age
- Job
- Marital Status
- Education
- Balance
- Housing Loan
- Personal Loan
- Contact Type
- Campaign Information
- Previous Marketing Outcomes
### Target Variable
- **y**
  - Yes → Customer subscribed
  - No → Customer did not subscribe
